These are my personal bibliography files, in [BibLaTeX](https://ctan.org/pkg/biblatex?lang=en) format. 

At the time of writing, August 2025, this repo is private.

The pseudo bib files called plants, animals, minerals, are databases for use with the LaTeX [Glossaries-extra](https://ctan.org/pkg/glossaries-extra?lang=en) package.  These files are meant to be
combined with the macros [described on my blog page](https://cikitsa.blogspot.com/2022/11/making-index-of-plant-names.html) to assist with identifying flora and fauna in Sanskrit texts
and auto-generating a glossary with cross-references and page indexing. This is being used in the [translation documents of the Sushrutaproject](https://github.com/wujastyk/sushrutaproject/tree/main/translation).
